# Data folder

Raw CICIDS2017 CSV files are not committed to this repo due to size.

## Download

1. Get the dataset from the Canadian Institute for Cybersecurity: https://www.unb.ca/cic/datasets/ids-2017.html
2. Download the 8 CSV files (MachineLearningCSV.zip)
3. Extract them into `ml-training/data/raw/`
